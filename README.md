# AIQuizLite

面向个人学习者和备考考生的本地 Android 刷题应用。

功能：

- 日常刷题：随机刷完整题库，做错自动加入错题本。
- 错题本：错题连续答对 3 次后自动移出。
- 模拟考试：172 题随机顺序，选项顺序打乱，最后统一交卷。
- 资料转题：导入 TXT、文字版 PDF 或 DOCX，按章节规划题量，由已配置的 AI 生成并经过两轮严格校验后保存为本地题库。
- 题库管理：支持 JSON/ZIP 兼容导入、编辑、图片、导出、下载库、备份与恢复。
- AI 辅助：支持 OpenAI 兼容接口的题目讲解、单题重生成和资料题目结构化。

资料转题的自动补齐最多运行 3 轮；只有有效题量、章节题量和题型配额完全一致时才能保存。资料不足时可调整计划、降低题量，或粘贴完整题目进行手动补题。

本地题库生成：

```powershell
python .\tools\extract_questions.py
```

构建 Debug APK：

```powershell
.\gradlew.bat assembleDebug
```
