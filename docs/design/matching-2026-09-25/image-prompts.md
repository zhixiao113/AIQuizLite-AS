## A 常规答题页

Use case: ui-mockup。生成精致、可落地的中文 Android 刷题应用 UI 设计对照图，横向画布，两张完整手机屏幕并列。不是网页，不用摄影背景。标题「A 常规答题页」，两屏分别标「提交前」「提交后」。延续 AIQuizLite 风格：#F9FAFB背景、白色圆角卡片、#2563EB主蓝、#111827文字、清晰中文字体。手机顶栏返回、日常刷题、收藏；题号「第 89 / 101 题」「连线题」。题干「请将 BGP 属性与对应类型连线」。规则「左侧可重复使用，右侧各选一项」。核心为紧凑双列卡片和中间足够清晰的连线走廊，左侧4项：1 公认必须遵循、2 公认任意、3 可选过渡、4 可选非过渡。右侧6项：1 Origin、2 团体属性、3 Next_Hop、4 Local_Pref、5 Originator_ID、6 Cluster_List。卡片边缘有明显圆形连接点，中文自然换行，线不穿过文字。两屏都画6条线：左1→右1、左1→右3、左2→右2、左2→右4、左4→右5、左4→右6。左屏所有线蓝色，无对错提示，状态「已完成 6/6 项」，按钮「撤销」「清空」，底部蓝色大按钮「提交答案」。右屏仅左2→右2红色并加×，其余5条绿色并加✓；结果「本题答错」「5 项正确，1 项错误」，结果区文字「团体属性：应连接 可选过渡」。不要额外画正确答案线，以免交叉混乱。右屏底部「查看正确连线」「下一题」。没有咨询浮窗，没有广告，没有提前泄露答案的图例。两个屏幕比例自然，完整包含底部按钮，不裁切，视觉清楚，适合用于产品评审。

修订提示：精确修正两屏左侧第 4 项为「4. 可选非过渡」，其余布局和连线不变。最终文件为 matching-a-submit-states.png。

## B 全屏连线工作区

Use case: ui-mockup。生成一张中文 Android 学习应用高保真 UI 评审图，标题「B 全屏连线工作区」，单张完整竖屏手机，白色清爽背景。与 AIQuizLite一致：#2563EB蓝色、#F9FAFB底、圆角白卡、黑色易读中文。顶部「‹ 返回题目」「第 90 / 101 题」。紧凑题干「VRRP 状态切换」「将事件与图中序号连线」。旁边可见文本按钮「查看题图」，不要凭空画状态图。规则「左侧可重复使用，右侧各选一项」。左右卡片中间保留连线走廊，每张卡片内侧圆形连接点。左侧5张自然高度卡片，完整文字依次为「1 收到 Startup，Priority < 255」「2 收到 Startup，Priority = 255」「3 收到 Shutdown 消息」「4 Master_Down 定时器超时，或收到优先级为 0 的通告，或收到比本地优先级低的报文」「5 收到比本地优先级高的报文」。右侧6张小卡「1」「2」「3」「4」「5」「6」，标题「图中序号」。长文本自然换行，Priority和255不逐字拆分，第四张显著更高，不能缩略或省略文字。已完成3条蓝线：左1→右3、左2→右1、左3→右2；左3到右4正在拖动，画一条蓝色虚线尾端小手势光圈，右4蓝色淡底高亮，这是操作吸附提示不是正确提示。底部固定栏「已完成 3/6 项」「撤销」「清空」，下方禁用灰色按钮「提交答案」，辅助文字「还有 3 项未连接」。所有节点都能看清，手机完整不裁切，底部安全区留白，无红绿对错、无答案、无广告或聊天浮窗。以一个沉浸式连线工作区呈现，文字比普通双列页面更舒展。
