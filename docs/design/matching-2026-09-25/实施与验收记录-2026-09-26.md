# 连线题实施与验收记录

截至 2026-09-26，连线题代码已接入数据、导入、答题、回看、题库编辑和备份链路，但**尚未完成真实 AI 导入与真机验收，不应发布**。本记录与《连线题操作与实现方案》的 V1—V9 门槛配套使用。

## 已实现

- `matching` 题型使用稳定的左右项目 ID 和关系对。支持一对一、左侧复用、未使用左侧项；每个右侧项必须恰好连接一次。练习提交前不显示对错，模拟考试交卷后判分。
- 常规答题页和可展开连线工作区共用作答草稿；支持拖动、点按、替换右侧连接、撤销、清空及提交后标准连线图。每日进度、历史快照、模拟考试、错题和答案修正保存连线关系。
- 现成题库 AI 转换提示词、紧凑协议、JSON/ZIP、题库编辑、AI 讲解及缓存键识别连线题和解析图。未知题型拒绝导入；含新字段的题库包使用 v2，完整备份写 v2 并读取旧 v1。
- 降低生成题量与恢复校对草稿时，章节题型统计已包含连线题，避免该类型丢失或计数出错。
- DOCX 读取正文图片位置和关系表，原文件暂存在应用私有校对草稿中。校对页可预览图片并选择作答题图或提交后解析图；保存时复制已选媒体至题库。原题号缺失、重复、非原卷号码、AI 未解析项及图片角色未确认均阻止保存。
- 本地检查：135 项 Debug 单元测试通过（0 失败），`lintDebug` 为 0 错误、120 条警告，`assembleDebug` 成功。原 DOCX 结构核对识别 1—101 题，其中 89—101 为 13 道连线题，媒体目录含 26 张图片。

## 实际操作

1. 在「总题库 → ＋资料」选择 `Datacom-IP_H12-821_03_试卷.docx`，确认 Token 消耗并按「现成题库」转换。
2. 在校对工作台核对原卷 1—101 题、13 道连线题及待人工校对清单。缺题不可用降低目标题量代替；打开题目编辑框补录原题号、左右项目及标准关系。图片像素未送给 AI，不能直接信任模型对图中内容的判断。
3. 对含图题用「原卷图片角色」预览并指定图片。第 89 题 `image12.png` 必须只选作提交后解析图；第 90 题 `image13.png`、第 98 题 `image23.jpg`、第 100 题 `image25.png` 必须作为作答题图。逐题检查其他图片后勾选图片角色确认，再保存题库。
4. 练习中把所有右侧项连完才可提交。故意连错一项，确认提交前全为待答状态、提交后错误连接显红色且可切换标准图；检查展开工作区与常规页草稿一致。模拟考试应在交卷后才显示正确性。
5. 再验每日中断恢复、历史回看、错题重练、答案修正、题库编辑与复制、ZIP 导出再导入、完整备份恢复；每次核对原题号、关系和图片角色不变。
