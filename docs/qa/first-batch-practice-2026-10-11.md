# 第一批优化：题型专项与连线操作

## 范围与使用

用户已同意执行：三个数据一致性修复、连线操作优化、按题型筛选练习。
本轮不包含章节练习、笔记、间隔复习、导入预览、AI 失败批次持久化或在线升级发布。

- 首页当前题库卡片新增「按题型练习」。仅显示当前题库存在的题型及题数；支持单选、多选、判断、填空、连线。
- 选择题型进入专项练习，题库顺序和原卷题号保持不变。不同题库、不同题型分别保存草稿、提交状态和当前位置；再次进入继续上次练习，完成后清除本轮专项进度。
- 专项作答仍遵守已有错题入库、移除阈值、收藏、答案订正、AI 讲解设置；不覆盖日常进度，也不追加整库日常历史记录。
- 连线操作栏移动到项目列表前，撤销/清空/展开使用一行。普通区和展开区共享作答及撤销栈；展开区「返回题目」不是提交，须在题目页点击「提交答案」。
- 蓝色起点/目标高亮仅表示手势位置，不表示正确。拖动到滚动区边缘并停留可持续滚动；结束、取消、离开视图时停止滚动。
- 清空连线需确认；右侧已连接项目可移除；保持连接点 44×48dp 触摸区域。提交、背题、历史回看保持只读。
- `sourceChapter`、`sourceName` 在导入、模型复制、编辑、答案覆盖、JSON/ZIP 导出和历史快照中保留。旧题库没有这些字段仍可使用；不改变格式版本。
- JSON/ZIP 导入和编辑保存统一拒绝空/重复题目 ID，错误标注题号。未提供 ID 的旧题库仍自动生成 `qN`，但与已有 ID 冲突时必须修正。
- 修改题库内容、删除题目或删除题库会清理相应专项草稿，避免继续旧数据；完整备份沿用现有整份进度偏好序列化，包含专项进度。

## 自动验证

构建目录：`artifacts/build-first-batch`。使用 `AIQUIZ_BUILD_DIR` 避免覆盖既有构建产物。

```powershell
$env:AIQUIZ_BUILD_DIR='E:/projects/project-bs/AIQuizLite-AS/artifacts/build-first-batch'
./gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --console=plain
```

- `QuestionMetadataTest`：导入/导出/历史保留来源；重复/空 ID 拒绝；缺省 ID 兼容。临时禁用新增导出字段和 ID 校验后，3 项测试全部失败；恢复修复后通过。
- `QuestionBankPackageManagerTest`：真实 ZIP 解包后重复 ID 拒绝、模型导出保留来源和空图片；既有 ZIP 图像、路径安全测试继续运行。
- `MatchingSelectionStateTest`：共享撤销栈覆盖连接、移除、清空和跨编辑器撤销；无效/重复操作不消耗撤销；还原草稿清理旧历史。视图接线和手势尚未做设备级自动化。
- `TypePracticeRulesTest`：筛选、规范化连线题、原题号保持、题库/题型隔离、不支持题型拒绝。
- `TypePracticePersistenceTest`：实际 ProgressStore 序列化搭配内存 SharedPreferences 边界，验证专项连线草稿往返、日常/不同题型/不同题库互不覆盖、删除及失效清理。

## 真机验收（待执行）

目前 ADB 没有连接设备，AVD 列表为空；构建通过不等于以下交互通过。

| 场景 | 操作与预期 |
| --- | --- |
| 日常进度隔离 | 在日常题填写未提交草稿；进入连线专项、退出并重进；两边各自保留原题与草稿。切换其他题型/题库不得串进度。 |
| 专项完成与历史 | 做完专项，查看结果计数；再次进入从头开始。首页日常历史记录数不变。 |
| 连线撤销 | 普通区连接第一条，展开连接第二条；返回普通区撤销第二条，再次展开撤销第一条。移除/清空也能跨区撤销。 |
| 提交门槛 | 未连全不能提交；全部连接后仍全部蓝线；点击提交才出现对错、正确连线和解析图。展开区返回不判分。 |
| 点击和拖动 | 两侧都能起拖；落到目标卡片生效；无效落点不新增连接；依次点连接点可连线，选中起点可见。 |
| 一对一/复用 | 一对一重复源被拒绝且不增加撤销步骤；复用题同一源可连接多个目标；重复同一连接不增加撤销步骤。 |
| 边缘滚动 | 长题拖到上下边缘并停住，继续滚动且连线跟随；松手/系统取消/关闭展开区后立即停止，不与左右切题手势冲突。 |
| 只读模式 | 背题、已提交题、历史回看含未作答题，普通区与展开区均不能修改；正确图切换、下一题/返回按钮正常。 |
| 排版 | 360dp 小屏及较小/标准/较大字体，操作栏不挤压文字，长中英文项目不遮连接点，底部提交按钮可见。 |
| 来源保留 | 带章节/来源的题库编辑题干或图片、复制、订正答案、导出 JSON/ZIP 再导入，来源字段不丢；历史仍使用原快照文本。 |
| 拒绝无效 ID | JSON 与 ZIP 导入重复/空 ID，显示具体题号而非创建半成品；正常旧题库和 Datacom 101 题包仍导入。 |
| 备份与升级 | 仅在明确的测试环境验证完整备份恢复专项草稿。正式升级须沿用已安装应用签名；本轮 Debug APK 不作为覆盖升级包。 |
