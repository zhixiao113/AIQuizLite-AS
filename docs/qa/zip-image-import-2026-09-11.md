# ZIP 图片题库导入与刷题布局验收（2026-09-11）

## 已实现

- ZIP 接受任意名称的单个 JSON 题库（题目数组或含 name/questions 的对象）与 image/ 图片目录，兼容旧版 question-bank.json + images/ 格式。
- 支持一层外目录、UTF-8 BOM、图片子目录、相对路径、Windows 路径分隔符，以及不歧义的裸图片文件名；相对路径以 JSON 所在目录为起点。
- 本地文件选择、总题库入口、下载库与外部分享共用题库包导入实现。ZIP 选择后立即导入，JSON 继续支持编辑后保存。
- 本地文件导入在后台执行，ViewModel 保留跨 Activity 配置重建的任务，避免重复导入；导入图片使用已有本地图片存储与回滚逻辑。
- 刷题页普通模式顶部卡片上下内边距从 20dp 增为 32dp，上边距从 70dp 减为 16dp；紧凑模式上下内边距从 15dp 增为 24dp，上边距从 42dp 减为 8dp。XML 默认值与运行时设置一致。
