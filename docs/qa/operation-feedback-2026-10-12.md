# 操作反馈优化与验收，2026-10-12

## 用户问题与诊断结论

用户要求先优化现有模块，报告“操作反馈”开启后选择、收藏、提交不震动，随后确认手机为小米15，系统触感反馈未开启。原 Quiz/MockReview 已接 KEYBOARD_TAP，应用开关默认开启且使用同一共享设置；该 Android 接口遵守系统触感开关，应用开关不能保证系统关闭时仍震动。[Android 官方说明](https://developer.android.com/develop/ui/views/haptics/haptic-feedback)

另有软件漏接：普通/展开连线的连接、撤销、清空及移除未触发反馈。此次不修改系统设置、不绕过静音/触感政策、不新增振动权限，不扩展章节等新功能，不重新设计首页。

## 本次实现

- Quiz 选择、收藏、主操作和 Mock Review 收藏复用 OperationFeedback，使用适用于普通触摸的 VIRTUAL_KEY，而非键盘专用语义。
- 同时读取应用与系统开关；关闭任意一项即不请求。每次操作读实时状态，重启不是必要步骤。原偏好键/默认值/备份语义不变。
- 设置增加“测试轻微震动”。用户打开应用开关时试震一次；系统关闭时明确说明并以 Snackbar 提供“打开系统设置”，只有用户点击才打开声音设置。入口不存在/被限制时安全退回系统设置，无自动写入系统设置。
- 从系统设置返回仅更新说明和按钮状态，保留页面滚动位置，不自动试震。接口返回 true 只提示“已发送试震请求，请确认是否能感受到”，不把请求当作真实马达验收。
- 单选/判断、多选、填空框点击和模拟考试最终交卷确认使用用户点击反馈；恢复选项、填空内容和自动跳题不自动请求反馈。
- 连线成功改变答案、撤销、清空、移除在操作发起视图各请求一次；普通与展开视图共享状态时，刷新观察者保持静默。重复同一连线、无效操作、只读、恢复草稿、查看标准答案、重新挂载视图不自动震动。连线正确性仍只在提交后展示。
- 系统/设备拒绝请求或抛出异常时反馈可用性报告为不可用，不中断选择、收藏或提交。无直接 motor 调用，没有权限提示，没有后台持续震动。

## 小米15真机验收

1. 原签名覆盖更新，不卸载；确认题库、图片与学习进度保留。
2. 保持系统触感关闭，在应用设置开启操作反馈，应提示系统开关关闭；测试按钮不能宣称试震成功，不应强制震动。
3. 通过提示的设置入口手动开启系统触感，返回时说明应更新；点击“测试轻微震动”，自行确认轻微震感。
4. 单选/判断、多选选中和取消、填空框点击、收藏和取消、提交及模拟交卷确认逐项验证反馈。自动跳题和恢复草稿保持安静。
5. 普通与展开连线分别验证连接、撤销、清空、移除有轻微反馈；重复连线、无效连接、恢复/返回与只读状态无多余震动，提交前不泄露对错。
6. 关闭应用操作反馈后上述自定义反馈全部停止，系统其他应用与键盘设置不应被改变；重新开启不需要重启。
7. 系统开启但仍无法感受到时，记录 HyperOS 版本及触感强度/免打扰状态和测试提示，不用强制绕过系统或卸载来排查。
