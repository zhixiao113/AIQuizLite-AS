## 发布及真机验收边界

本记录初次提交时：远程代码/CI 与 code14 正式推广尚待随后执行；完成结果另行追加，不用本机成功代替远程工作流成功。云端签名 Secrets 尚未导入，不能宣称 GitHub 已自动签名构建。

ADB 只读检查无设备，不进行手机安装或数据操作。用户尚需确认实际手机网络可达及上云签名授权；第二个更高 code 的手机升级演练不提前打包成假验收。

待真机逐项验证：

1. 现有手机从旧版本覆盖升级到过渡包，原题库、图片、错题、收藏、进度、专项练习草稿和设置保留。
2. 在 Wi-Fi/移动网络下，GitHub 清单检查、版本说明、下载进度与安装确认正常；无更新与网络失败不混淆。
3. 拒绝安装权限后给出提示；允许后重试。取消、断网、返回、旋转/重建页面及重复点击不会误触发安装。
4. 约定验收窗口从过渡包升级到另一个真实更高 code 的同签名包，证明不是仅上传 APK 或模拟网络。
5. 撤回清单后未升级设备不再获取撤回包，已安装设备不自动降级；后续修复 code 大于最高已用值。
6. 本地 BAT 仍选择当前产物、签名/版本校验正常；新版手机的本地入口需有效 TLS 或明确内网 HTTP，旧 FRP 证书若不可信会拒绝，不宣称已验收。

本轮不触及学校虚拟机、Nginx/Docker、应用题库内容或签名私钥原文件。
